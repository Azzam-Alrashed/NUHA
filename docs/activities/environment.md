# «رحلة مطابقة البيئة» (`environment`)

Status: draft, written by the developer from the SRS and the built activity (milestone 3). Not reviewed by an educator; every Arabic line below is draft (`@DraftArabic` in code).

## Learning objective
Match an everyday thing to the place or weather it belongs to.

## Prerequisites
Recognises the pictures; can drag, or tap instead.

## Successful behaviour
Drags the item into an accepted environment, or taps the environment (the item is already picked up). Each item has a set of accepted environments.

## Likely confounds
Drag precision (a drop that lands on no environment is a miss, not a wrong answer); picture style; vocabulary.

## Examples
Places: المطر (rain), البحر (sea), الحديقة (garden). Items: المظلّة, حذاء المطر → rain; السمكة, القارب → sea; الوردة, الفراشة → garden.
Instruction «أين مكان <item>؟»; praise «أحسنت! مكان <item> هو <place>.»; model «مكان <item> هو <place>. ضع <item> هناك.» (phrased to avoid gender agreement with the item).

## Accessibility alternative
Tap the environment instead of dragging (FR-ACT-005).

## Difficulty factors
Environments on screen 2 → 3.

## What is recorded
`misses` = drops outside every environment.

## Transfer question
For the educator to set.
