# «نسخ الأنماط الهندسية» (`patterns`)

Status: draft, written by the developer from the SRS and the built activity (milestone 3). Not reviewed by an educator; every Arabic line below is draft (`@DraftArabic` in code).

## Learning objective
See a repeating rule in a row of shapes and continue it.

## Prerequisites
Tells circle, triangle and square apart by outline.

## Successful behaviour
Continuation mode: tap the next shape. Drawing mode: trace the next shape on the pad. Sessions alternate modes (PLACEHOLDER `patternMode`).

## Likely confounds
Drawing mode shows the next shape's outline to trace, which gives the answer away; see the milestone 3 report. Shapes differ by outline, not colour.

## Examples
Instruction «ما الشكل الذي يأتي بعد ذلك؟» / «ارسم الشكل الذي يأتي بعد ذلك.»; praise «أحسنت! بعد ذلك يأتي <shape>.» Shape names دائرة، مثلث، مربع.

## Accessibility alternative
Continuation mode is tap only.

## Difficulty factors
Rule AB → AAB → ABC, moving one level every second session so each mode changes one factor at a time.

## What is recorded
Drawing mode: strokes, attempts, detail `coverage;stray`. Session difficulty includes `mode`.

## Transfer question
For the educator to set.
